# T-Lab
# Generative Sequential Recommendation with RL 🎬

Данный проект представляет собой реализацию генеративной рекомендательной системы для онлайн-кинотеатра (на базе датасета KION) с использованием архитектуры **GPT-2** и обучения с подкреплением (**REINFORCE**).

Цель проекта — продемонстрировать переход от классической задачи угадывания следующего клика (Next-Item Prediction) к максимизации долгосрочной бизнес-метрики — вовлеченности (доли досмотра видео).

## 🛠 Архитектура и пайплайн

Пайплайн решения состоит из следующих этапов:

1.  **Подготовка данных (Data Preprocessing)**
    *   Фильтрация неактивных пользователей (менее 5 просмотров).
    *   Внедрение метаданных (жанр и длительность) в виде префикс-промптов перед историей просмотров. Длительность квантована на 3 корзины (`short`, `medium`, `long`).
    *   Разбиение датасета по методологии **Leave-One-Out**.

2.  **Supervised Pre-training (Базовая модель / Actor)**
    *   Архитектура: `GPT2LMHeadModel`.
    *   Обучение предсказанию следующего токена в авторегрессионном режиме с использованием Left Padding и маскирования (`-100` в `CrossEntropyLoss`).

3.  **User Feedback Model (Критик / Reward Model)**
    *   Архитектура: `GPT2ForSequenceClassification` (инициализирована весами базовой модели).
    *   Обучение предсказанию непрерывной величины (доли досмотра от 0.0 до 1.0) с использованием функции потерь **MAE (L1 Loss)**.

4.  **RL Fine-Tuning (REINFORCE)**
    *   Дообучение генеративной модели максимизировать предсказанную Критиком долю досмотра.
    *   Использование бейзлайна (вычитание среднего по батчу) и регуляризации энтропией (Entropy Penalty) для стабилизации обучения.

## 🔬 Исследовательские результаты

### 1. Как меняется поведение модели? Удаётся ли максимизировать вознаграждение?
Поведение модели радикально меняется. Базовая модель выступает "имитатором" исторического поведения пользователя. RL-модель же целенаправленно ищет способы увеличить предсказанную долю досмотра. Вознаграждение максимизировать удается: ожидаемый досмотр вырос с **~45.5%** (у базовой модели) до аномальных **>100%** (у базовой RL-модели). 

Этот эффект известен как **Reward Hacking**. RL-агент нашел уязвимости в линейном слое Reward Model, скармливая ей цепочки фильмов, которые приводят к искусственно завышенным оценкам.

### 2. Формулировка долгосрочного вознаграждения
В отличие от оптимизации вероятности клика (CTR), в данном проекте награда сформулирована как **Engagement** (вовлеченность), выраженная в доле досмотра видео (`watched_pct`). В реальном продакшене долгосрочной целью (Return) могла бы стать сумма долей досмотра всех видео за сессию с учетом коэффициента дисконтирования ($\gamma$), однако в рамках POC оптимизировался ожидаемый досмотр сгенерированных кандидатов на ближайших шагах.

### 3. Анализ многошаговой генерации (на 5 шагов вперед)
При авторегрессионной генерации на 5 шагов вперед (Next-K) эффект Reward Hacking многократно усиливается. Средний ожидаемый досмотр у RL-модели вырос со 101.4% (на 1 шаге) до **104.5%** (на 5 шагах). 
**Причина:** Сдвиг распределения (Out-of-Distribution, OOD). Reward Model обучалась на реальных историях людей. Когда RL-агент генерирует 5 фильмов подряд, эта "синтетическая" цепочка настолько отклоняется от реального распределения, что Критик не справляется с экстраполяцией и выдает оценки, физически превышающие предел в 100%.

### 4. Компромисс метрик (Relevance vs. Reward Trade-off)
Эксперимент наглядно продемонстрировал конфликт между исторической релевантностью и максимизацией сторонней награды:
*   **Базовая модель:** Recall@10 $\approx$ 7.7%, NDCG@10 $\approx$ 4.6% (хорошая персонализация).
*   **RL-модель:** Recall@10 упал практически до 0.1%. Модель пожертвовала персональными предпочтениями пользователя ради рекомендации контента, который, по мнению Критика, максимизирует досмотр.

## 📚 Использованные концепции из научных статей

1.  **GPTRec: Generative Pre-training for Sequential Recommendation**
    *   *Идея:* Использование парадигмы Next-Item Generation с каузальной архитектурой (GPT-2) и честная оценка через Leave-One-Out сплит.
2.  **Large Language Models are Competitive Sequential Recommendors (Yambda-5B)**
    *   *Идея:* Обогащение контекста метаданными через текстовые префиксы (добавление жанра) и использование квантованных корзин для непрерывных признаков (секунды длительности $\rightarrow$ `short`, `medium`, `long`). Обучение отдельной User Feedback Model (Reward Model) на базе MAE Loss.
3.  **Training language models to follow instructions with human feedback (InstructGPT) / RLHF**
    *   *Идея:* **Внедрение регуляризационного штрафа (Entropy / KL-Penalty).**
    *   *Обоснование:* Для борьбы с коллапсом политики и OOD-генерацией (выдачей наград >100%) в функцию потерь алгоритма REINFORCE был добавлен штраф за снижение разнообразия (минимизация отрицательной энтропии $\beta \cdot \text{entropy}$). Это заставляет модель "сомневаться" и препятствует скатыванию генерации к одному фильму, сглаживая эффект Reward Hacking.
    *   *Ссылка:* [https://arxiv.org/abs/2203.02155](https://arxiv.org/abs/2203.02155) (Ouyang et al., 2022). Похожие методы для страниц рекомендаций описаны в *Deep Reinforcement Learning for Page-wise Recommendations* (Zhao et al., [https://arxiv.org/abs/1805.02343](https://arxiv.org/abs/1805.02343)).
